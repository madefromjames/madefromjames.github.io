A Few Projects

Browse through my portfolio to see examples of my work and projects.

eBay Auction Site

An eBay-like e-commerce auction site developed using Django, allowing users to post auction listings, place bids on listings, comment on listings, and add listings to a watchlist.

Stock Market

A financial management tool built with Flask, enabling stock trading, transaction tracking, and cash balance management. Users can manage and monitor their stock portfolio in real-time, with an intuitive interface for tracking investments.

Birthday Tracker

A Flask-based application for managing birthdays. Users can add, edit, and delete birthday entries, making it easy to keep track of important dates.

Wiki

A Django-based application that allows users to create, edit, search, and view encyclopedia entries stored in Markdown format. The Markdown content is converted to HTML before being displayed, providing a user-friendly interface for managing and exploring entries.

Word Jumble Game

A word guessing game built using Tkinter. Players are presented with a shuffled word and must guess the correct word to earn points. The game offers options to reshuffle the letters, get hints, or skip words if players are stuck. It tracks lives and points, creating a fun and challenging experience.
